Trimble TBC FXL Library Builder

This tool turns collector “slang” (PointID + Description) into a canonical code library you can import into Trimble Business Center using Convert CSV to FXL.
Input Collector CSV (P,N,E,Z,D)
Output FXL_Definitions_Points.csv
Library master-library.json (shared + versioned)
Template reference: fxl template.csv

Workflow (4 steps) Auto-load: checking…

1
Library
Loads master-library.json automatically if it exists next to this page. You can also load a library from your company folder, and export an updated version back.
Recommended company workflow: keep an “official” master-library.json in a shared folder. Each user exports a timestamped update and one person promotes it to the official file.
2
Collector CSV
Load any collector CSV with columns in this order: PointID, Northing, Easting, Elevation, Description. If Description is blank, the tool treats PointID as the description.
Nothing here changes your field data. This tool builds the definitions file for TBC’s CSV→FXL import.
3
Review queue
If something is unknown, it maps to REVIEW.UNMAPPED. Use review items to teach the library once (Exact/Prefix/Regex), and it will map automatically next time.
4
Export for TBC
Exports FXL_Definitions_Points.csv (Point feature definitions only). In TBC: Survey → Field Data → Convert CSV to FXL.
Convert CSV to FXL reference: Trimble Help – Convert CSV to FXL
What this page produces (and what it doesn’t)
Produces: a Feature Definition CSV (Point definitions) suitable for TBC’s Convert CSV to FXL import.
Does not: modify your collector CSV or “auto-draft” geometry yet. That comes later when you adopt feature processing / linework rules inside TBC.
The exported definitions CSV uses the Point header from your template: Name, Code, Category, Feature Layer, Label Style, Color, Include in Surface, Attributes (name and type) [Template: fxl template.csv]
